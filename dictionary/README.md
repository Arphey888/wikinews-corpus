## 📋 Столбцы

| Столбец | Значение |
|---|---|
| `lemma` | Начальная форма в нижнем регистре. «Ё» приведено к «е». |
| `pos` | Тег части речи pymorphy3, например `NOUN`, `ADJF` или `VERB`. `PROPN` обозначает имя собственное, `NONE` — неопределённую часть речи. |
| `freq` | Число употреблений пары «лемма + часть речи» в обработанном корпусе. |
| `known` | `1`, если хотя бы одна словоформа этой пары найдена в словаре pymorphy3, иначе `0`. |

## 🧭 Обработка и происхождение

Скрипт `build_dictionary.py` разбивает текст на последовательности русских букв, допускает дефис внутри слова и выбирает наиболее вероятный разбор pymorphy3 2.0.6 без учёта контекста. Модуль `name_filter.py` помечает известные имена собственные и эвристически отбрасывает предложения с признаками нерусского текста. Омонимия частей речи влияет на частоты.

Словарь содержит производные частотные данные. Для исходных текстов Русских Викиновостей действует [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), если на странице не указано иное. При использовании указывайте Русские Викиновости и авторов исходных статей, давайте ссылку на лицензию и отмечайте изменения. В корпус входят материалы с `origin_type = external_import`, для которых могут действовать условия внешних источников. Происхождение отдельных статей описано в карточке корпуса.
